# База реалистичных лиц для UGC

Исходники — реальные селфи (папка `realman_for_ugc/`). Из них делаем кейфреймы под персоны
сценариев (`scripts/ugc_keyframe.py`), лицо не придумываем с нуля. Каталог машиночитаемый: `faces.json`.

| id | исходник | на фото | подходит для | как адаптировать |
|---|---|---|---|---|
| m01 | `realman_for_ugc/01.jpg` | ~48, седина на висках, борода с проседью, светлые глаза | 50–60: здоровье, долголетие, финансы, «папа/муж» | +10 лет: больше седины, морщины у глаз; спорт, офис, машина |
| m02 | `realman_for_ugc/02.jpg` | ~40, тёмные волосы, щетина с проседью, худи | 35–45: продуктивность, приложения, путешествия | улица/город, рюкзак; не старить больше чем на 8 лет |
| m03 | `realman_for_ugc/03.jpg` | ~40, короткая стрижка, щетина, в машине | 35–50: «по дороге с работы», финансы, ментальное здоровье | машина/кухня, рубашка |
| m04 | `realman_for_ugc/04.jpg` | ~38, спортивный, майка, зеркальное селфи | фитнес, питание, GLP-1, трекеры | зал/раздевалка; для говорящей головы нужен кейфрейм крупным планом |

## Готовые кейфреймы (`faces/keyframes/`)
`<id>_<сцена>.png` — проверенные кадры, которые уже можно оживлять в Kling. Каждый новый кейфрейм
проходит чек-лист из `rules/ugc-realistic-face.md` и только потом попадает сюда.

## Как пополнять базу
1. Реальное селфи (не сток, не генерация), лицо ≥ 40 % кадра, ровный дневной свет, без очков и фильтров.
2. Положить в `realman_for_ugc/` (или `realwoman_for_ugc/`), добавить строку сюда и в `faces.json`.
3. Сделать 2 базовых кейфрейма: «говорящая голова на улице» и «дома/в машине».
