# Правило: эндкарта (End Card)

Утверждено Дмитрием 12.11.2026 на пачке Example App «Biological age».
Плохой пример: `bad_examples/04_endcard_system_font.png`: иконка с рваными краями и белым ореолом,
«Example App» и слоган системным жирным шрифтом с белой обводкой поверх 3D-кадра. Выглядит незадизайненным.
Хороший пример: `good_examples/04_endcard_designed.png`.

## Обязательно
1. **Иконка только оригинальная из App Store**, не перерисовка и не скрин. Найти приложение:
   `curl "https://itunes.apple.com/search?term=<бренд>&entity=software"` и сверить продавца и иконку. Скачать 1024:
   в `artworkUrl512` заменить `512x512bb.jpg` на `1024x1024bb.png`. Положить в `projects/<проект>/brand/app_icon_1024.png`.
2. **Скругление делаем сами** маской `border-radius: 22.37%` (как в iOS), на квадратном PNG из стора.
   Никакой белой или цветной обводки, ореолов и glow вокруг иконки. Допустима мягкая тень снизу.
3. **Антиалиасинг**: рендерим в полном разрешении ролика (1440×2560, `render_html.py --size 1440x2560`,
   device scale ×2), кодируем `crf ≤ 18`. Кадр эндкарты проверяем с кропом ×2: края иконки и букв без ступенек.
4. **Шрифты**: название Inter Tight 800, слоган Inter 600, CTA Inter Tight 800. Системные шрифты (SF, Arial, Helvetica)
   запрещены. У текста нет `stroke`, обводок и ореольных `text-shadow`.
5. **Фон**: чистый кадр сцены без старого текста. Если в исходной эндкарте текст вшит, делаем «чистую подложку»
   (nano-banana-pro/edit: убрать иконку, текст и кнопку, остальное не трогать) и даём медленный наезд 1.00→1.035.
   Для читаемости используем градиентную подложку под текстом: тёмную для белого текста, светлую для тёмного (`ink`).
6. **Анимация**: иконка 0.86→1 с easeOutBack за 0.5 с, текст по очереди fade и slide, CTA снизу,
   затем лёгкая пульсация. Без рывков и вращений.
7. Слоган и CTA берём из оригинала ролика, у каждого ролика свои. Цвет кнопки равен цвету иконки.

## Инструменты
Шаблон `templates/end_card/end_card.html`, параметры в `window.CFG`: `bg`, `icon`, `title`, `tagline`, `cta`,
`ink: light|dark`, `accent`, `t0`, `dur`:
```
python3 scripts/render_html.py templates/end_card/end_card.html - <t0> <t1> ec.mp4 --size 1440x2560 --cfg ec.json
```
Затем подклеиваем вместо старой эндкарты, звук ролика не меняем.

## Чек-лист
- [ ] иконка из App Store, скругление 22.37 %, без обводки и ореола;
- [ ] края иконки и текста гладкие на кропе ×2;
- [ ] шрифты Inter Tight / Inter, без stroke;
- [ ] старый текст и кнопка с фона убраны полностью;
- [ ] слоган читается на любом фоне.
