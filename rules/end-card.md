# Правило: эндкарта (End Card)

Утверждено Дмитрием 12.11.2026 на пачке Longy «Biological age».
Плохой пример: `bad_examples/04_endcard_system_font.png`: иконка с рваными краями и белым ореолом,
«Longy» и слоган системным жирным шрифтом с белой обводкой поверх 3D-кадра. Выглядит незадизайненным.
Хороший пример: `good_examples/04_endcard_designed.png`.
Ещё плохой пример: `bad_examples/07_endcard_flat_small_type.png` (garmin11–14, 12.11.2026): «Longy» повторяет иконку,
слоган и «Works with your Garmin» мелкие и серые (размеры прыгают без шкалы), середина кадра пустая, фон — размытое
тёмное лицо героя (выглядит грязно, не как реклама), кнопка плоская и неподвижная, нет причины нажать.

## Уровень по умолчанию (коммерческая эндкарта)
1. **Заголовок — выгода, а не название.** Название уже на иконке. Пример: «Know your real biological age», 2 строки,
   Inter Tight 900, ~105 px при 1080.
2. **Шкала размеров** (px при 1080): заголовок 100–110, CTA 56–64, подпись 44–50, плашки ≥ 44. Ничего мельче 44 px.
   Шаг между уровнями ×2–2.5.
3. **Фон** по варианту: `brand` — градиент из цвета иконки в тёмный; `hero` — чистый кадр продукта
   (часы, кольцо, браслет) с мягкой подложкой под текст; `product` — экран приложения в iPhone на тёмном фоне.
   Размытый тёмный кадр героя — только по прямой просьбе.
4. **Социальное доказательство только с реальными данными**: рейтинг из iTunes API
   (`https://itunes.apple.com/lookup?id=<id>` → `averageUserRating`), без округления вверх. Нет данных — нет плашки.
5. **Кнопка живая**: вход пружиной, пульс и блик. Ничего не стоит дольше 1.5 с: иконка «дышит», свечение фона двигается.
6. **Переход из ролика мягкий**: последний кадр ролика (`from`) растворяется за 0.35 с, без жёсткой склейки.
7. **Склейка по номеру кадра, а не по секундам.** Начало старой эндкарты в оригинале — это индекс кадра;
   режем `trim=end_frame=N`. Секунды с округлением вверх оставляют 1–2 кадра старой эндкарты
   (BIOLOGICAL AGE_04/08/09/10_v2: мелькал кадр со старой эндкартой перед новой).
   После сборки обязательно запускаем `scripts/cut_check.py`.
Какой вариант брать: есть чистый кадр продукта → `hero`; нет → `brand`; если в ролике мало экранов приложения → `product`.

## Обязательно
1. **Иконка только оригинальная из App Store**, не перерисовка и не скрин. Найти приложение:
   `curl "https://itunes.apple.com/search?term=<бренд>&entity=software"` и сверить продавца и иконку. Скачать 1024:
   в `artworkUrl512` заменить `512x512bb.jpg` на `1024x1024bb.png`. Положить в `projects/<проект>/brand/app_icon_1024.png`.
2. **Скругление делаем сами** маской `border-radius: 22.37%` (как в iOS), на квадратном PNG из стора.
   Никакой белой или цветной обводки, ореолов и glow вокруг иконки. Допустима мягкая тень снизу.
3. **Антиалиасинг**: рендерим в полном разрешении ролика (1440×2560, `render_html.py --size 1440x2560`,
   device scale ×2), кодируем `crf ≤ 18`. Кадр эндкарты проверяем с кропом ×2: края иконки и букв без ступенек.
4. **Шрифты**: название Inter Tight 800, слоган Inter 600, CTA Inter Tight 800. Системные шрифты (SF, Arial, Helvetica)
   запрещены. У текста нет `stroke`, обводок и ореольных `text-shadow`.
5. **Фон**: чистый кадр сцены без старого текста. Если в исходной эндкарте текст вшит, делаем «чистую подложку»
   (nano-banana-pro/edit: убрать иконку, текст и кнопку, остальное не трогать) и даём медленный наезд 1.00→1.035.
   Для читаемости используем градиентную подложку под текстом: тёмную для белого текста, светлую для тёмного (`ink`).
6. **Анимация**: иконка 0.86→1 с easeOutBack за 0.5 с, текст по очереди fade и slide, CTA снизу,
   затем лёгкая пульсация. Без рывков и вращений.
7. Слоган и CTA берём из оригинала ролика, у каждого ролика свои. Цвет кнопки равен цвету иконки.

## Инструменты
Шаблон `templates/end_card/end_card.html` (варианты `hero` / `brand` / `product`), параметры в `window.CFG`:
`variant`, `icon`, `accent`, `headline`, `sub`, `partner`, `rating`, `store`, `cta`, `screen`, `bg`, `from`, `t0`, `dur`.
Прошлая версия с подложкой-кадром: `templates/end_card/end_card_v1_plate.html`.
```
python3 scripts/design_lint.py templates/end_card/end_card.html - <t0> <t1> --cfg ec.json      # обязателен, код 0
python3 scripts/render_html.py templates/end_card/end_card.html - <t0> <t1> ec.mp4 --size 1080x1920 --cfg ec.json
python3 scripts/cut_check.py final.mp4                                                        # после сборки, код 0
```
Затем подклеиваем вместо старой эндкарты, звук ролика не меняем.

## Чек-лист
- [ ] иконка из App Store, скругление 22.37 %, без обводки и ореола;
- [ ] края иконки и текста гладкие на кропе ×2;
- [ ] шрифты Inter Tight / Inter, без stroke;
- [ ] старый текст и кнопка с фона убраны полностью;
- [ ] слоган читается на любом фоне;
- [ ] заголовок — выгода, шкала размеров соблюдена, ничего мельче 44 px;
- [ ] рейтинг/отзывы только реальные; кнопка анимирована; переход из ролика мягкий;
- [ ] cut_check пройден: нет мелькания старого кадра перед эндкартой.
